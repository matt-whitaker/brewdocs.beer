# BrewDocs

BrewDocs is an offline homebrewing application and info handbook.

### Stack

#### Application (app.)
- [React](https://react.dev/)
- [Tanstack](https://tanstack.com/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Daisy UI](https://daisyui.com/)
- [Vite](https://vite.dev/)

#### Marketing ([www.])
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Daisy UI](https://daisyui.com/)
- [Astro](https://astro.build/)
