# @brewdocs.beer/www

Marketing / info site. Deployed to [brewdocs.beer](https://brewdocs.beer).

## Entry points

- [`src/pages/`](src/pages/) — `index.astro` (`/`) and `about.astro` (`/about`)
- [`src/data/env.ts`](src/data/env.ts) — `PUBLIC_*` env vars

## Stack

- [Astro](https://astro.build/) with [React](https://react.dev/) islands
- [Tailwind CSS](https://tailwindcss.com/) / [Daisy UI](https://daisyui.com/)

See the [`www` section of CLAUDE.md](/CLAUDE.md#packageswww) for detail.
